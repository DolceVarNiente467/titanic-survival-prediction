## English

# Titanic Survival Prediction 🚢

Predicts whether a Titanic passenger survived, using real 1912 data from Kaggle.
**Model:** Logistic Regression
**Accuracy:** 80.45%

## Features
Age, Sex, Pclass, family members aboard

## Cleaning
- Filled missing ages with median
- Dropped Cabin column (77% missing)
- Converted text columns to numbers

 ## Source
Data from [Titanic - Machine Learning from Disaster](https://www.kaggle.com/c/titanic) on Kaggle

By Shahad, IT student
